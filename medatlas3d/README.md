# 🧬 Bio animations

Interactive 3D Human Anatomy Suite & Clinical Education Platform.

## Features

- **Realistic GLB 3D Organ Models**: Heart, Lungs, Liver, Brain, and Kidneys sourced from NIH Visible Human & clinical datasets.
- **Cross-Sectional Anatomy**: Real-time slicing on Sagittal, Coronal, and Transverse planes.
- **Physiological Audio**: Real-time Web Audio API cardiac cycle (lub-dub) and breath murmurs.
- **Clean Clinical Aesthetic**: Modern obsidian/slate dark theme with surgical cyan accents (no AI purple gradients).
- **Clinical Quizzes**: Board-style question modules with instant rationales.

## Scripts

- `npm run dev`: Start Vite development server (port 5173)
- `npm run server`: Start Express REST API server (port 5001)
- `npm run dev:all`: Start both the API server and Vite concurrently
- `npm run build`: Build production optimized client bundle
- `npm run preview`: Preview the production build locally
